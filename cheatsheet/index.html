A4 paisagem · 1 página
Visão geral
9 voicings × 4 instrumentos numa única folha. Denso — use como cheat tátil, não pra estudo prolongado.
Como gerar os PDFs: abra cada link acima, Ctrl+P (Cmd+P no Mac) → no diálogo, "Save as PDF" / "Salvar como PDF". As páginas têm @page size embutido (A4 ou A3 paisagem) — o browser configura sozinho. Marque "Background graphics" / "Cores e imagens de fundo", senão os A3 saem brancos.

Para os A3 paisagem: garanta que o diálogo de impressão está em orientação paisagem (alguns browsers tentam retrato por padrão). O @page no CSS já força, mas conferir no preview ajuda.

Combinação: os 4 A3 podem ser impressos lado a lado em um único A1 (594×841mm) se a gráfica aceitar arte combinada. Cada A3 individualmente também funciona.
